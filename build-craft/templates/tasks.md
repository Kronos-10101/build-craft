# Tasks

Every task needs a binary done-condition. Format: `- [ ] <task> — owner: <name> — done when: <binary condition>`.
Every checkbox line below (EXAMPLE or real) MUST contain "done when:" — the gate enforces this.

- [ ] EXAMPLE: scaffold the module skeleton — owner: Alice — done when: `pytest tests/test_skeleton.py` passes
- [x] EXAMPLE: read the routed domain checklist — owner: Alice — done when: checklist quoted in grill.md

- [ ] <task> — owner: <name> — done when: <binary condition>
- [ ] <task> — owner: <name> — done when: <binary condition>
- [ ] <task> — owner: <name> — done when: <binary condition>
